# SECCIÓN 2: FASE 1 - INSTALACIÓN DE PLUGINS (15 MIN)

## Paso 1.1: Instalar Rank Math
```
1. Plugins > Añadir nuevo
2. Buscar "Rank Math"
3. Instalar y activar
4. Al activar, ejecutar el asistente de configuración
5. Seleccionar "Modo avançado" cuando pregunte
6. Dejar valores por defecto
```

## Paso 1.2: Configurar Rank Math rápidamente
```
1. Ir a Rank Math > Dashboard
2. Clic en "Take the Tour" y skip
3. Ir a Titles & Meta > Global Templates
4. En "Homepage" poner:
   - Title: Dragon Ball HD Sin Límites | Ver Episodios Online
   - Description: Disfruta de todos los episodios de Dragon Ball, 
     Dragon Ball Z, GT, Super y Kai en español latino y subtitulado. 
     Actualizaciones semanales gratis.
```

## Paso 1.3: Instalar Contact Form 7
```
1. Plugins > Añadir nuevo > Buscar "Contact Form 7"
2. Instalar y activar
3. Ir a Contacto > Formularios de contacto
4. Copiar el shortcode del primer formulario: [contact-form-7 id="XXX" title="Contacto"]
5. Crear página "Contacto" y pegar el shortcode en el editor
```

## Paso 1.4: Instalar Imagify
```
1. Plugins > Añadir nuevo > Buscar "Imagify"
2. Instalar y activar
3. Ir a Settings > Imagify
4. Crear cuenta gratis en imagify.io y obtener API key
5. Pegar API key en la configuración
6. En "Optimization" seleccionar "Aggressive"
7. Marcar "Automatically optimize newly uploaded images"
```

## Paso 1.5: Instalar Wordfence
```
1. Plugins > Añadir nuevo > Buscar "Wordfence"
2. Instalar y activar
3. Ir a Wordfence > All Options
4. Scroll hasta "Login Security" y activar "Enable login without password"
5. Dejar todo lo demás por defecto
```

## Paso 1.6: Instalar Enable Media Page
```
1. Plugins > Añadir nuevo > Buscar "Enable Media Page"
2. Instalar y activar
3. Ir a Medios > Enable Media Page
4. Revisar los medios que faltan alt text
```

```apache
# Security Headers
<IfModule mod_headers.c>
    Header set X-Content-Type-Options "nosniff"
    Header set X-Frame-Options "SAMEORIGIN"
    Header set X-XSS-Protection "1; mode=block"
    Header set Referrer-Policy "strict-origin-when-cross-origin"
    Header set Permissions-Policy "geolocation=(), microphone=(), camera=()"
</IfModule>

# Protect wp-config.php
<files wp-config.php>
    order allow,deny
    deny from all
</files>

# Protect .htaccess itself
<files ~ "^.*\.([Hh][Tt][Aa])">
    order allow,deny
    deny from all
    satisfy all
</files>
```
